# Codex Environment Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configure a dependency-free Codex Desktop environment with fail-fast setup, local preview, and repository validation actions.

**Architecture:** Store the complete Codex Desktop integration in one repository-local `.codex/environments/environment.toml`. Keep commands inline because the static site has no package manager or task runner, and verify each configured script by reading it back from TOML and executing the exact stored value.

**Tech Stack:** TOML v1 configuration, POSIX shell, Node.js built-in test runner, Python 3 `http.server` and `tomllib`

## Global Constraints

- Setup must only verify Node.js and Python 3; it must not install packages, access the network, write generated files, or start background processes.
- Common actions are exactly `Preview Site` and `Validate Site`.
- Preview must bind to `127.0.0.1:4173`.
- Validation must run the three commands documented in `README.md` in fail-fast order.
- Git, Azure deployment, package managers, task runners, secrets, and global Codex settings are out of scope.
- Do not touch the unrelated untracked `.codex/` or `package-lock.json` in the main checkout at `/Users/aserdargun/Documents/ChatGPT/aserdargun.com`.

- [x] **Step 6: Execute the configured preview action and probe all public routes**

Run:

```bash
python3 - <<'PY'
from contextlib import closing
import subprocess
import time
import tomllib
from urllib.request import urlopen

with open(".codex/environments/environment.toml", "rb") as handle:
    config = tomllib.load(handle)

command = next(action["command"] for action in config["actions"] if action["name"] == "Preview Site")
server = subprocess.Popen(["/bin/sh", "-c", command], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
try:
    deadline = time.monotonic() + 5
    while True:
        try:
            with closing(urlopen("http://127.0.0.1:4173/", timeout=1)) as response:
                assert response.status == 200
            break
        except OSError:
            if time.monotonic() >= deadline:
                raise
            time.sleep(0.1)

    for route in ("/en/", "/tr/"):
        with closing(urlopen(f"http://127.0.0.1:4173{route}", timeout=1)) as response:
            assert response.status == 200
    print("Preview action served /, /en/, and /tr/ successfully.")
finally:
    server.terminate()
    server.wait(timeout=5)
PY
```

Expected: `Preview action served /, /en/, and /tr/ successfully.` and exit status 0; the preview process is terminated in `finally`.
